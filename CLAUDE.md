# RGB-Diffusion — instructions pour les agents de T.A.Z.

Dépôt **public** de diffusion : README, LICENSE et Releases (installateurs, `SHA256SUMS`, archives de sources). Aucun
code de travail, aucun workflow.

- Les Releases sont créées par le job de publication du dépôt de développement, jamais à la main par un agent.
- **Public** : rien de la maison (noms de machines, chemins, horaires, échéances, décisions internes), aucun lien vers
  un dépôt privé, aucun secret, aucun prix ni mention de revenus.
- Ce dépôt est un miroir : son contenu est la copie de `diffusion/` du dépôt de développement, déjà relu ; ne pas le modifier ici.
- Chaque Release publiée doit contenir les sources de Bombe et d'OpenRGB de la version livrée (GPL).
